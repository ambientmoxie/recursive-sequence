# Recursive Sequence

<img src="docs/recursive-cover.png" width="500" />

A recursive, nested structure of ellipses. Each click generates a new layout. Adjust the composition's complexity by tweaking the config object.

## Usage

### Prerequisites

- [Node.js](https://nodejs.org) or [Docker](https://www.docker.com)

### Run

**With Node**

```
npm install
npm run dev
```

**With Docker**

```
docker-compose up
```

Then open `http://localhost:5173/wire-mesh`.
